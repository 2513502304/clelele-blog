# 主题与阅读设置

右下角工具栏的调色盘按钮打开设置面板。十个预设包括原色日常、花间手记、纸上画廊、林间书屋、海盐来信、紫藤小院、琥珀午后、玫瑰木、铅笔与墨、蓝调印刷。每个预设都支持明暗两种状态；顶部日月按钮继续控制明暗，调色盘负责选择色调，两者可以组合。

这些设置保留现有导航、侧栏、卡片和图片比例。纸上画廊与铅笔与墨使用衬线字体和细微纸纹，其余预设沿用站点字体。文字大小有标准、舒适、大字三档，对应默认字号的 100%、106.25%、112.5%。图片本身不套滤镜，查看和复制的仍是原图。

面板可用鼠标从非输入控件区域拖动，包括预设按钮表面；短点击选择预设，超过拖动距离才移动面板，不会顺带切换主题。焦点在面板内时，Alt + 方向键也能移动。标题可以收起内容，选择区有独立滚动条，Esc 或右上角关闭按钮关闭面板。手机窄屏会限制面板宽度，避免伸到屏幕外。

切换色调时，新外观从右下角向左上角沿柔和的对角线展开。系统开启“减少动态效果”，或浏览器不支持 View Transitions 时，直接应用结果；不会因此无法切换。毛玻璃也有减少透明度和高对比度的备用样式。

偏好只保存在当前浏览器的 localStorage，不写 HF、不改变其他访客的设置。刷新和站内跳转会恢复选择，同一浏览器的其他标签页也会同步。如果隐私设置禁止本地存储，仍可调整当前页面，但刷新后不会保留。点击“恢复默认”会恢复原色与标准字号，保留原来的明暗偏好。

开发维护时，预设清单在 `src/components/theme/appearance.ts`，配色变量在 `src/styles/theme/appearance.css`。新增预设时，两处需要同时更新，并检查明暗状态、字体放大、手机宽度和快速连续切换。四个布局实验移到了 `src/dev/design-lab.astro`，只由开发服务器注入路由，不能重新加入生产导航或 sitemap。
