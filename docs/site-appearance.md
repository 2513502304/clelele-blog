# 主题与阅读设置

右下角工具栏的调色盘按钮打开设置面板。“外观预设”负责整页配色，“阅读与界面”调整文字和控件；两组设置可以自由组合。顶部日月按钮仍负责明暗模式，每个主题都有浅色和深色版本。

## 18 个外观预设

面板每行三个预设，共六行。配色会改变页面的大面积背景、卡片、标题和按钮，图片本身不套滤镜。

| 第一列 | 第二列 | 第三列 |
| --- | --- | --- |
| 原色日常：站点原有配色 | 花间手记：粉色底 | 纸上画廊：暖纸色、衬线字与纸纹 |
| 林间书屋：灰绿色 | 海盐来信：浅海蓝 | 紫藤小院：淡紫色 |
| 琥珀午后：暖金色 | 玫瑰木：红棕色 | 铅笔与墨：灰色、衬线字与纸纹 |
| 蓝调印刷：灰蓝色 | 薄荷汽水：薄荷绿 | 柠檬奶油：奶油黄 |
| 桃杏果园：桃杏色 | 冰川清晨：冰青色 | 桑葚果酱：莓紫色 |
| 沙丘旅人：沙褐色 | 开心果绿：黄绿色 | 月下石阶：冷灰蓝 |

切换时，新配色从右下角向左上角沿柔和的对角线展开，约 600 毫秒完成。动画中可以继续选另一个主题，最终采用最后一次选择。拖动设置面板、滚动页面或调整窗口大小时，会立即结束当前动画，避免截图与新位置错开。系统开启“减少动态效果”、设置中选择“立即切换”，或浏览器不支持 View Transitions 时，直接显示新配色。

## 独立调整阅读和界面

| 设置 | 可选范围 | 实际影响 |
| --- | --- | --- |
| 字号 | 默认字号的 85%–130%，滑块或数字输入 | 页面文字与使用 rem 的尺寸随之变化；设置面板保持稳定大小 |
| 正文行距 | 1.4–2.2 倍 | 文章段落、列表和面板内的示例文字 |
| 字体 | 跟随主题、系统黑体、宋体/衬线、等宽 | 正文和标题，使用设备已有字体，不额外下载字体 |
| 界面密度 | 紧凑、常规、宽松 | Gallery 卡片间距及主要内容卡片的内边距 |
| 卡片圆角 | 利落、圆润、柔和 | 主要内容区的卡片；圆形头像保持原样 |
| 控制面板 | 毛玻璃、实色 | 使用共用玻璃样式的控件、主题面板及多选浮动工具栏 |
| 主题动效 | 对角线展开、立即切换 | 主题切换及设置面板的展开动效；系统的减少动态效果优先 |

字体的最终字形取决于设备安装的字体。切换主题不会覆盖独立设置，例如选过宋体后再换配色，仍会使用宋体；选择“跟随主题”可恢复该主题的默认字体。

面板可以从非输入控件区域拖动，预设按钮表面也可以：短点击选择主题，拖动超过阈值才移动面板。滑块、输入框和下拉框保留各自的操作。焦点在面板内时，Alt + 方向键也能移动面板；标题收起内容，Esc 或右上角按钮关闭。选择区独立滚动，手机窄屏会限制面板宽度。

## 保存与恢复

偏好保存在当前浏览器的 localStorage，不写入 HF。刷新、站内跳转和同一浏览器的其他标签页会恢复或同步选择。隐私设置禁止本地存储时，仍可调整当前页面，但刷新后不会保留。“恢复默认”会重置配色和全部阅读设置，保留明暗模式。

旧版“标准、舒适、大字”会分别迁移为 100%、106%、113%，已有字号偏好不会突然丢失。新设置保存后，以新的数值为准。

## 维护时需要保留的约束

预设名称在 `src/components/theme/appearance.ts`，颜色在 `src/styles/theme/appearance.css`；两处需同步增加。阅读选项和校验规则在 `reading-preferences.ts`，首屏脚本与 React 控件共用这些规则，防止刷新前后出现不同结果。

View Transition 只捕获旧页面的 `#appearance-stage`，设置面板通过 portal 放在外面。更新配色后，新页面退出捕获，旧截图用渐变遮罩退场。不能改回捕获整个 root：[规范规定，已捕获的内容不会参与正常指针命中](https://www.w3.org/TR/css-view-transitions-1/)，单独给截图设置 `pointer-events: none` 也无法恢复按钮点击。旧截图的原始高度、滚动偏移和遮罩的视口高度需分别处理，避免长页面在动画中错位。

浏览器回归检查包括真实坐标连续点击、滚动后转场中间帧、滑块按住期间往返拖动、字号输入、明暗文字对比度、跨页恢复和手机面板。连续点击不能只用自动等待动画结束的定位器操作来验证。截图按 CSS 像素采样，避免高分屏的设备像素比例影响结果。

详情页 sub-images 默认复用 Gallery 的瀑布流，按钮可以切换为网格；布局写入 URL 的 `layout` 参数。改变密度后须重新计算瀑布流间距，但不能改变图片的 DOM 顺序、平台分组、选择状态或 lightbox 浏览顺序。

四个布局实验仍在 `src/dev/design-lab.astro`，只由开发服务器提供，不能加入生产导航或 sitemap。
