# Live2D 资源与工作室

2026-10-29 的同步结果：Bestdori 五区合集由 3,477 套增至 3,551 套，本次新增的 74 套全部发布；Our Notes 三个公开索引按模型 ID 去重后共 261 套，已发布为独立、不可变的 HF 资源包。两个游戏保留不同服装 ID，同一人物通过完整姓名或明确的舞台名别名合并。

Bestdori 的资源仍属于 Girls Band Party，并不包含 Our Notes 原生模型。本次新增原生格式适配，而非将新游戏模型转换成旧游戏模型。HF 沿用既有 `raw-datasets/bestdori` 存储前缀；每个资源包的 provenance 单独记录真实来源、版本和校验值。

## 访客使用

看板娘工具栏的「Live2D 工作室」打开大面板。桌面左侧为预览，右侧是编辑区；手机上下排列。颜色、字体、圆角和弹窗行为沿用博客主题。

| 区域 | 功能与范围 |
| --- | --- |
| 角色 | 按来源、角色或服装搜索；选择时才下载对应模型 |
| 表情与姿态 | 模型自带动作、表情；按参数名搜索和微调；使用模型声明的数值边界 |
| 姿态文件 | 本地导入/导出 JSON，仅用于同一个角色和服装；拒绝超过 100 KB 的文件和不匹配的模型 |
| 画面 | 原色、柔光、胶片、黑白、鲜明、夜色六种滤镜；透明、暖纸白、浅粉、深色四种背景 |
| 构图 | 人物缩放、水平/垂直位置、说话人和短对白 |
| 导出 | 本地生成长边 1,600 px 的 PNG；透明背景可导出透明图；对白按导出画布重新排版，最多五行 |

关闭工作室会清除本次参数微调；需要保留时先导出姿态。选中的角色、服装和已有看板娘偏好继续沿用原有存储方式。并非每个模型都有表情或独立动作。Our Notes 不复用旧游戏的语音触发映射。

参考了用户提供的两个视频所展示的表情编辑、画面滤镜和角色构图方向，未照搬网站 UI 或编辑器代码。本功能不包含录像、剧情时间轴、麦克风、摄像头或 AI 生成服务。

## 性能边界

- 工作室 React 模块按打开动作加载；Our Notes 引擎和 Cubism Core 仅在选择原生模型时加载。
- 工作室与看板娘移动并复用同一个画布、同一个已加载模型。切换原生/旧引擎才更换画布，避免混用 WebGL 上下文。
- 原生渲染为 30 fps，DPR 上限 1.5；手动暂停和隐藏状态停止连续绘制。暂停时修改参数只请求一次更新。
- 原生资源并发上限为四个；不可变地址沿用浏览器/CDN 缓存。切换模型取消旧请求并等待旧渲染释放，避免同时持有多个会话。
- 工作室不预载整个资源库、不持续采集参数、不额外建立第二个动画循环。PNG 仅在点击导出时生成，下载 URL 会释放。
- CSS 不动画插值弹窗几何尺寸，避免旋转屏幕时连续改变 WebGL 缓冲区大小。

Bestdori 合集中有 29 个历史条目未发布：27 个模型描述地址返回 HTML，`007_dream_festival` 的纹理地址返回 HTML，`l2d_res_00001` 属于非角色资源。不可把这些条目误报为本次新增模型导入失败。

原生资源保留 split/gzip 文件、纹理、moc3 和游戏 shader；下载时校验传输长度、解压后长度及 SHA-256。发布使用内容寻址和条件写入，目录采用 ETag 比较更新，避免覆盖其他同步任务的数据。

```sh
# 使用已有 HF 发布配置与代理环境；不要将凭证写入文件或提交。
npm run sync:live2d-our-notes -- --plan-only
npm run sync:live2d-our-notes -- --models adv_live2d_anon_002_casual_spring_01_glasses
npm run sync:live2d-our-notes -- --publish
# 先部署支持原生包的博客版本，再公开目录：
npm run sync:live2d-our-notes -- --publish --commit-catalog
```

所有索引、下载、HF 和 Git 网络操作经代理执行。`--publish` 只写不可变包；`--commit-catalog` 要求同时指定 `--publish` 且本批次无失败。未知或空模型选择会报错。新版本替换已有服装需走显式的版本更新流程，脚本不会静默覆盖。

旧客户端仍请求默认目录接口，服务端排除原生模型；新客户端通过 `?native=1` 获取完整集合。部署回滚时应保留这一兼容层或先恢复不含原生模型的目录。

## 验证与已知限制

浏览器验证覆盖：真实 HF 原生资源、参数编辑、暂停时零连续 GPU draw、PNG 下载、关闭重开不重新下载模型、旧/新引擎切换、手机布局、暗色主题、移动端唤醒前零模型传输和 Astro 导航复用。另单独验证了演出服模型 `live2d_yuno_015_live_01` 的非空渲染和动作列表。资源校验覆盖全部包，但没有逐一人工审查 261 套模型的全部动作。

在 Chromium 软件 WebGL 验证中，爱音眼镜便服模型的透明边缘和部分纹理出现颗粒；同一资源在未修改的上游 `ModelPlayer` 中也能复现。不能将其宣称为已完成的画质提升，也不能保证所有设备、所有模型完全复现游戏画面。

运行时采用未修改的 `ournotes-player@0.1.1` 浏览器发行物，保留 AGPL 与前端嵌入例外；Cubism Core 保留官方授权声明。详见 [vendor 说明](../public/vendor/ournotes-player-0.1.1/README.md)。模型美术权益仍归各自权利人，数据来源记录不代表取得新的授权。
