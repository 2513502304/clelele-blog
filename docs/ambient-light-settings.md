# 环境光设置与 Edge 插件对照

本页对应「主题与阅读 → 横幅 → 画面环境光」。环境光使用当前横幅的原始颜色，在视口背后固定显示；横幅遮罩、图片滤镜、标题、主题与粒子效果各自独立。设置旁的 **?** 支持鼠标悬浮、键盘聚焦和点击，说明调整对象、数值方向及保护限制；Esc 先关闭说明，滚动面板时说明自动收起。

## 当前默认与操作建议

| 设置 | 默认 | 调整后会看到什么 |
| --- | --- | --- |
| 遮罩方式 / 强度 | 薄雾柔光 / 30% | 强度越高，横幅上的淡色薄雾越明显 |
| 底部衔接 | 雾化消融 | 横幅下缘逐渐融入页面，无硬切边 |
| 画面环境光 | 全页漫射 | 当前横幅的色块铺满背景，滚动到下方仍保留 |
| 光晕强度 | 100% | 降低后整体光场变淡，主题背景更明显 |
| 柔化程度 | 30% | 增大后色块边界更模糊；0% 仍保留基础柔化 |
| 扩散范围 | 0% | 增大后放大光场，色块更宽、周边裁切更多；0% 已覆盖视口 |
| 主题底色融合 | 0% | 增大后投影混入更多当前主题底色 |
| 页面底衬 | 35% | 两栏共用的阅读底色；增大更清淡、减小更通透 |
| 投影亮度 / 对比度 / 饱和度 | 各 100% | 仅调整背景光，不修改横幅或内容图片 |
| 边缘羽化 / 文字柔光 | 30% / 20% | 前者控制外缘淡出，后者保护内容文字辨识度 |

想保留浓郁原色，先调低「页面底衬」，无需更换主题。想让正文更稳重，调高底衬或选择实色。内容卡片至少保留 78% 底色。所有页面共用你选择的底衬数值，不再因 About 或文章含有正文而暗中提高到 88%。对于极亮或极暗的原图，可主动选择 88% 底衬提高阅读对比度。实色模式优先。底衬是平滑的阅读保护，不会对图片或文字施加透明度。

「保留画面：左右 / 上下」调整的是 **被裁切图片的取景位置**。0% 优先保留左侧 / 顶部，100% 优先保留右侧 / 底部；没有对应方向的裁切时，拖动不会移动画面。面板会提示该情况，环境光也跟随同一取景。

已有浏览器保存的值会保留；「重置横幅」恢复横幅及环境光默认，「重置氛围」只恢复粒子。底部「恢复默认」还会重置主题与阅读设置。

## 原始插件逐项说明

对照对象是用户截图中的 [Ambient Light for YouTube](https://github.com/WesselKroos/youtube-ambilight)。名称和范围核对了它的 [设置定义](https://github.com/WesselKroos/youtube-ambilight/blob/master/src/scripts/libs/settings-config.js)；Colors 与视频混帧机制参考其 [WebGL 实现](https://github.com/WesselKroos/youtube-ambilight/blob/master/src/scripts/libs/projector-webgl.js)。核对日期：2026-10-08。插件版本可能继续调整选项。

**采用** 表示已有对应能力，不代表算法、百分比刻度与插件完全相同；**部分** 表示简化或近似；**未采用** 表示当前没有该项。开关或枚举没有「越大 / 越小」，表内说明启用或各选项的区别。视频专用项没有移植到静态横幅。

| Resolution | 投影分辨率；越高细节越多、纹理内存和处理量越大 | **部分**：固定低分辨率 96×64，适合模糊背景；没有滑块 |

| Synchronization | Decoded 跟随解码；Display 跟随屏幕刷新、开销较高；Video 跟随实际视频帧回调 | **未采用**：没有视频时间轴 |
| Save energy on static videos | 视频画面基本静止时减少更新；原版可降至数秒一帧 | **采用同类原则**：横幅不变就不重绘，滚动不触发绘制，无需用户开关 |
| Prioritize page load speed | 页面加载后才启动环境光，减少抢占初始加载 | **部分**：等待已有横幅解码，复用图片，不另行下载；不刻意等待全页网络空闲 |
| YouTube responsiveness fixes | 优化 YouTube 评论、播放列表、时间轴等特定 DOM 的响应 | **未采用原实现**：网站结构不同；本站单独优化固定光场和按需绘制 |
| Optimize debanding for | LCD 与 OLED 的抖动方式；OLED 模式尽量保留纯黑 | **未采用**：没有屏幕类型配置，也不叠加噪声纹理 |

### 环境光、空间渐变与时间平滑

| 原始设置 | 含义与数值方向 | 本站是否采用 |
| --- | --- | --- |
| Blur | 模糊投影色块；越大越朦胧，纹理处理范围也增大 | **采用**：柔化程度；本站 0% 有基础模糊，刻度不与插件一一对应 |
| Edge size | 视频边缘参与投影的几何范围；越大边缘区域越宽，关闭 Blur 更容易看出形状差别 | **未直接采用**：本站「边缘羽化」控制淡出，不是该参数的复制 |
| Spread | 光场向外扩散距离；越大覆盖更远，处理区域可能更大 | **部分**：扩散范围改为放大视口投影；0% 已铺满视口，不是光晕距离为零 |
| Spread fade start | 开始衰减的位置；越大越晚开始、近处保留更多光色；负值可提前到画面内部 | **未独立开放**：固定渐变起点，配合方向与羽化 |
| Spread fade curve | 衰减曲线；原版值越大，遮罩幂指数越小，中途衰减更强；值小则更接近边缘才快速衰减 | **未独立开放**：采用平滑 CSS 渐变，避免把几何淡出误称为时间动画 |
| Ambient light → Debanding (noise) | 给投影加入抖动噪声缓解大面积色带；越大越有颗粒 | **未采用**：保留干净光场，避免持续噪声绘制 |
| Fade in duration | 画面变换时环境光过渡时长；越长越慢、更柔和，但跟随更迟 | **未采用时间混合**：静态横幅改变时重新投影，主题转场另行管理 |
| Flicker reduction | 减少帧间亮度剧烈波动；越高抑制越强、响应可能越迟 | **未采用**：不处理视频闪烁 |
| Smooth motion (frame blending) | 混合相邻视频帧，使环境光运动更连续 | **未采用**：静态光场不保留多帧纹理 |
| Smooth motion strength | 上一项混帧强度；越高越柔滑，也更易拖影 | **未采用**：视频专用 |
| Fixed position | 固定光场相对视口的位置，不随页面滚动离开 | **采用并固定启用**：侧栏与正文共享同一个视口背景，无滚动监听器 |

## 回归原因与实现边界

PR #74 的第一版 `f11a39c` 只有一个固定环境光背景，通过降低对比度获得淡色效果。第二版 `ba9cdbd` 保留原色后，为侧栏、内容与长文分别增加局部底衬，其中侧栏至少 88%、主区域默认 35%；因此颜色看起来不同。第三版 `27f5b8d` 合并成文档高度的渐变层，但侧栏仍保持 88%。图库渐进加载后，这张双重遮罩可延伸到数万像素高。

本次移除文档高度遮罩，把阅读底衬放到固定环境光的同一视口合成中。两栏和不同路由都使用同一个用户设置，不根据内容类型追加底衬。布局和卡片渐进加载不再改变光场几何；图片不变时不重绘，纯 CSS 设置不再清除/恢复 `data-ready`，也不强制读取图片尺寸。

快速滚动中尚未加载的卡片仍可能展示占位内容，这是渐进加载状态，并非第二张环境光画布。没有通过一次性加载全部图片来掩盖这个状态。环境光关闭、横幅损坏或源未解码时回退主题背景；图片和标题仍由自己的设置控制。

### 验证方法

- Chromium 与 WebKit：60,000px 长页面，对比侧栏和主区域空白处像素；快速滚动及停止后采样；断言没有文档高度底衬。
- Chromium 移动帧使用 CDP 不带文档坐标裁切的视口截图，避免截图矩形与异步滚动竞争产生整张白图。
- 18 个主题、嵌套详情与文章页面、实色模式、环境光关闭/坏图回退、控件拖动与持久化。
- 设置帮助检查全部配置项、三种语言、悬浮、聚焦、点击、Esc、窄屏边界与滚动关闭。

### 滚动与缓存检查（2026-10-08）

此前把旧 CSS 追加到新 CSS 后比较的合成测试，会继承仅存在于新版本的规则，不能作为隔离版本的性能基准。撤回该测试的「光栅化减少 31%」结论。现在使用真实 React 图库、192 条隔离目录数据和多张不同颜色的 1664×2432 图片测试，不克隆 DOM 卡片，不查询或写入生产数据。

回归测试检查真实渐进加载、向下再向上滚动、已加载图片的请求计数和 URL 稳定性，以及每段滚动中粒子是否继续绘制。单元测试与 Chromium/WebKit 实际挂载测试覆盖签名过期后新实例使用有效地址、当前已显示图片保留 URL、真实图片错误仍可回退；共享加载历史不会使新实例复用过期签名。

本轮本机量测挂载了 192 张卡片，从 19,500px 滚回 650px，已加载图片新增请求为 0；粒子在滚动期间绘制 118 次，最大帧间隔约 158ms，最长主线程长任务 105ms。没有整段滚动暂停，但仍存在短暂丢帧，不能据此承诺所有设备都无卡顿。

- 卡片不会在离开视口时主动卸载；返回已加载卡片不应主动更换图片 URL。浏览器仍可能在内存压力下回收解码像素，重新解码不等于重新下载。
- 粒子不会因为滚轮事件暂停。标签页隐藏、减少动态效果或关闭氛围才会暂停；主线程和浏览器合成繁忙仍可能丢帧。
- 横幅滤镜和阅读字号调整不再清空或重启无关的粒子动画。静态环境光不使用动画循环。
- Lightbox 热预加载保留既有数量与像素预算；本轮没有把所有原图一次性加载，也没有降低卡片原图清晰度。

回归测试：`GALLERY_SCROLL_FIXTURE=1 npx playwright test --config playwright.generation-notes.config.ts gallery-scroll-cache`。

本机量测：先运行 `GALLERY_SCROLL_FIXTURE=1 node --import ./tests/style-gallery/generation-fixture.mjs node_modules/astro/astro.js dev --host 127.0.0.1 --port 4340`，再运行 `node tests/style-gallery/ambient-scroll-bench.mjs`。它报告当前版本的请求、挂载卡片、粒子帧间隔和主线程长任务，不声称生产 FPS 或跨设备收益。不要与 Astro build/check、浏览器测试或其他量测并行运行。
