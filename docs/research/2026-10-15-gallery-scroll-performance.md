# Gallery 滚动性能排查

本轮修复了会挤占动画执行时间的侧栏重复扫描，并减少长列表的图片解码、布局测量和离屏毛玻璃开销。没有通过隐藏卡片、滚动时暂停粒子或改变环境光默认值来换取性能。

后续 sub-images 缩略图与 Lightbox 预载/缓存改动见 [图片加载诊断](2026-10-16-gallery-image-loading.md)。下文“详情使用原图”指本轮状态；后续详情页的 sub-image 卡片使用预览，参考主图与 Lightbox 仍使用原图。

## 原因与改动

| 已确认的问题 | 改动与边界 |
| --- | --- |
| HomeInfo 监听整个 body，每条新增节点记录都会安排一次延迟全页扫描。图库追加卡片、图标加载都会触发它 | 使用单个委托点击监听器，点击时才查找该侧栏的折叠区域。延迟插入的手机抽屉和 Astro 切页同样有效 |
| 约 270px 宽的列表卡片直接解码数千像素原图 | 优先使用已有 720px 预览。预览不存在或损坏时回退原图；Lightbox、详情和下载仍使用原图；两者缓存身份独立 |
| masonry 在 children 更新后重建观察器并重读全部高度 | 保留观察器和高度，追加只测新卡片；宽度、字体、图片实际尺寸变化仍更新位置。顺序、比例和键盘定位不变 |
| 长列表所有玻璃徽章都保留 backdrop-filter | 只对距视口超过 1200px 的卡片关闭徽章模糊，接近视口时恢复。卡片、文字、图片始终保留，着色和形状不变 |
| 快速滚动时，追加后 sentinel 可能仍在预加载范围内，后续批次停在 48 张 | 挂载数量变化时重新观察 sentinel，继续按原有 24 张批次加载 |

粒子代码没有滚动暂停逻辑。本轮未改它的速度、数量或颜色；隐藏标签页、减少动态效果和用户关闭特效时仍暂停。

## 诊断证据和限制

- 生产页只读检查时有 648 张卡片；空白现象不能仅用“有没有重复网络请求”判断。DOM 和已加载图片仍存在，浏览器重新栅格化、解码或主线程阻塞也可能出现视觉空档。
- 使用实际 React 渐进挂载构造 672 张卡片。CPU 采样定位到 `HomeInfo.initCollapsible → document.querySelectorAll` 约 6.17 秒；同场景修复前后诊断的 ScriptDuration 分别约 6.42 秒、0.18 秒。这里只说明移除了扫描负担，不能换算成线上 FPS 提升百分比。
- 1664×2432 样例变成 720px 宽预览后，单张源像素面积减少约 81%。这是输入像素需求，不是浏览器或 GPU 实测内存。
- 最后一次 672 张卡片的独立滚动诊断：已加载图片重复请求 0，粒子持续绘制 125 帧，视口附近保留模糊的控件 124 个。诊断屏蔽 Astro 开发工具 X-ray（生产环境不存在），图片由本地 fixture 提供。
- 同一次无头 Chromium 压力测试中，粒子帧间隔 p95 约 125ms，最大约 171ms；因此**没有证据承诺所有设备持续 30/60fps 或完全消除掉帧**。真实 Edge 前台合成体验仍应在预览部署上验收。测试时现有 Edge 标签页报告 hidden，未将后台标签页结果作为前台帧率证明。

## 回归覆盖

新增浏览器断言覆盖：追加不重测旧卡片、不扫描全页侧栏；离屏卡片仍显示且返回时恢复玻璃；尺寸变化和布局切换不重叠；预览与原图缓存隔离；预览早于 hydration 失败时仍回退；延迟侧栏副本、键盘折叠和切页后操作有效。

沿用已有缓存过期、返回滚动无重复下载、滚动期间粒子绘制、追番/手办比例、三行 prompt 内部滚动和主题渐变回归测试。检查、构建和浏览器服务器串行运行，避免共同改写 Vite 缓存。

最终结果：31 项图库/缓存/侧栏浏览器路径、56 项主题/横幅/详情浏览器路径通过；Gallery 单元测试 160 项通过；Astro check（0 errors、0 warnings）和生产构建通过。Biome 全库检查通过，保留未改动 `src/lib/content/categories.ts` 的一个未使用导入提示。Knip 执行后仍报告 85 个未使用文件、12 个依赖、225 个导出等全库问题，本轮不做无关清理。

## 复现长列表诊断

先启动独立服务器：

```sh
GALLERY_SCROLL_FIXTURE=1 GALLERY_SCROLL_ITEM_COUNT=672 node --import ./tests/style-gallery/generation-fixture.mjs node_modules/astro/astro.js dev --host 127.0.0.1 --port 4340
```

另一终端运行：

```sh
GALLERY_BENCH_LONG=1 node tests/style-gallery/ambient-scroll-bench.mjs
```

使用新浏览器上下文，不读写线上 Gallery 数据。诊断是当前版本单机样本；不要把不同缓存、视口或运行模式的结果作为严格版本对照。
