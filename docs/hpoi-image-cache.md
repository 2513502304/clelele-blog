# Hpoi 同构图高清缓存

2026-11-16。生产以 Cloudflare 容器为准；Vercel legacy 已暂停。

## 当前流程

`/api/hpoi` 读取 HF 的 `hpoi-images/manifest.v1.json`，在返回列表前附加不可变图片 URL、原封面宽高和回退图片。浏览器不跑 CV，也不再从评分请求取得第一张官图。卡片采用固定占位比例，缓存图失败只尝试一次原封面缓存，再显示缺图占位。

公开收藏中新出现的 ID 会进入 Node 容器的单 worker 后台队列。新匹配在下一次收藏快照刷新时出现。已完成 ID（包括低置信度回退）直接跳过，不因刷新、切换分类或封面 URL 的日期参数变化而重跑匹配。元数据仍按原逻辑更新。失败退避一小时；容器中断时没有完成记录，下次读取收藏会重新发现。后台任务不承诺容器休眠期间继续执行，完整回填使用下面的 CLI。

```sh
npm run sync:hpoi-images -- --dry-run
npm run sync:hpoi-images
npm run sync:hpoi-images -- --ids=85291,70818,68456,128755
```

默认公开用户 783694，可用 `--user=ID` 更改。CLI 三个有界 worker，重复执行只处理缺失 ID；失败返回非零退出码，已成功 ID 不回滚。不提供自动覆盖已有匹配的开关，避免普通刷新改变已确认的构图。

## 匹配和资源

- `/cover/n/` 与 `/pic/n/` 的文件名没有可计算映射，不能替换目录名猜原图。
- 详情页官图首批最多 12 张。后续用官网公开图库接口，参数 `ndoeId` 是原站拼写，offset 步进 12；拒绝重复页和缺少标记的错误页。
- 缩略图 404 时再试高清原图；只有两者都确认 404 才跳过该照片并记录 `unavailable`。403、超时和服务异常仍使本条目延期重试。实测 111451 的图库保留了一个已删除链接，其余官图可正常匹配。
- 先用同一官图的 `/pic/s/` 小尺寸版本排序，选中后下载 `/pic/n/` 并重新对齐。不同于 `/cover/`，这两个官图尺寸保留同一拍摄构图。
- 原封面归一化到 48×64 RGB；搜索候选图 45%–100% 高度范围内的缩放/平移裁切，再细化局部位置，计算 8×8 局部 SSIM。PSNR 对大面积白背景、包装盒不够可靠，未用作唯一排序。
- 高清匹配分数至少 0.67，同时领先第二候选 0.045；高于 0.9 的近重复照片可通过。这个阈值是保守启发式，不是语义识别。低置信度、没有官图或有效裁切像素不大于封面时，保留原封面。
- HF 保存原封面、选中的高清原图，以及按封面构图裁切后的高清 JPEG。未选中的官图仅保留 URL/匹配分数，不长期存储，减少带宽与空间。选中 JPEG 原图保留下载字节；展示裁切版使用 quality 95，不把放大的封面冒充高清。
- 每个条目另外保存不可变的 `completed/ID.json` 完成凭据。索引暂时读旧或发布中断时，先检查此凭据并修复索引，不重新下载/匹配官图。首轮 117 条记录已补齐凭据。
- `objects/<sha256>.jpg` 内容寻址；所有引用对象上传成功后再 CAS 合并 manifest。并行进程不会丢掉对方的条目。中断留下的未引用对象不影响前台，也不自动删除其他资源。
- 使用已有 HF S3 凭据，但前缀独立于 Gallery/Live2D。公开图片端点只允许 64 位 hash JPEG，不能访问任意 HF 对象。

## 回归证据与已排除方案

用户反例：85291/70818 应为第二张官图（70818 第一张为盒子）；68456 为第一张；128755 的第三张与 77004 的第一张属于正确构图；完整图库中还存在同构图的其他版本，最终可以选中更接近封面的版本。`tests/fixtures/hpoi` 保存缩小的封面和前三张官图供离线回归，不需要测试访问 Hpoi。

直接缩放后计算 SSIM 曾把 70818 的背面排到正面之前，也无法认出 85291 裁切后的正面。加入裁切对齐后这五个样本均选对；不能退回“取图库第一张”或只比较未对齐像素。对于更多视角、背景接近但姿态不同的图片，宁可回退封面。

77004 名称没有额外换行符：全站标题的 `text-wrap: balance` 造成提前折行。卡片单独设为自然换行，取消两行截断，完整名称也保留在 title 属性中；窄卡片仍会正常折行。

128755 在本次读取时封面/官图均返回有效 JPEG，未复现持续的源站故障。用 HF 的匹配第三张及封面缓存消除运行时对该 CDN 的依赖；不要把暂时 403/502 当成文件不存在。

验证：`npm run test:hpoi`；`npm run check`；`npm run build:cloudflare-container`；`playwright test --config playwright.blog.config.ts tests/blog/hpoi.spec.ts`。发布后应检查 Cloudflare 的新 API 返回和图片字节，不能只看静态资源或 build success（容器切换可能晚于 Worker 静态资源）。
