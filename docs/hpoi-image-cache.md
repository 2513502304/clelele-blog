# Hpoi 官图原文件缓存

2026-11-16 更新。生产以 Cloudflare 为准；Vercel legacy 已暂停。

## 当前约定

**卡片只展示匹配到的 `/gk/pic/n/` 原文件。** HF 对象、API 响应和源站文件应具有相同 SHA-256、像素尺寸、格式和字节数。不裁切文件、不 resize、不重新编码、不把 PNG 转 JPEG；不以低置信度或裁切像素不足为由退回 `/cover/n/` 或 `/pic/s/`。

实测用户指出的 126224 图片 `2026/06/5d6d11dbb44549c49bd3ba4282c96f1c.jpg`：`pic/s` 是 400×560、30,815 字节；`pic/n` 是 750×1050、115,136 字节。原图本身的分辨率因上传文件而异，不能把小原图放大后称为高清。

`manifest.v2.json` 与 `completed-v2/ID.json` 隔离旧裁切/封面记录。首次迁移复用 v1 的候选排序和已缓存 JPEG 原文件；PNG 重新下载原文件。已有 v2 条目直接跳过；仅新增条目读取图库和运行匹配。v1 和旧图片保留用于回溯，不删除其他 HF 资源。

前端快照改为 `hpoi-snapshots-v4`，API 查询为 `images=original-v2`，避免浏览器与 CDN 继续返回旧缩略图地址。API 的 `x-hpoi-image-policy: original-v2` 标识原图协议；部署切换期间若 CDN 中混入旧容器响应，前端用 Range 请求绕过共享缓存，只有协议正确的结果才允许写入快照。尺寸在图片加载前返回，卡片按原图比例预留空间；HF 出错只回退到同一 `/pic/n/` 源文件。索引读取失败返回 API 错误，让客户端保留上次完整快照；新条目匹配完成前显示占位，不降级到低清封面。

## 匹配、人工核验与特殊图片

- `/cover/n/` 与 `/pic/n/` 文件名没有通用可计算映射。详情页与公开图库接口提供官图地址，分页 12 张，参数 `ndoeId` 是原站拼写。
- **空 HTML 图库不代表没有官图。** 130013 仅有空容器，必须读取 offset=0；本次找到了 35 张官图。之后继续完整分页。
- `/pic/s/` 只用于后台低成本候选排序，不能成为展示文件。缩略图 404 时尝试对应 `/pic/n/`，两者均 404 才跳过。403、超时或其他异常延期重试。
- 新候选先做相同缩放/平移对齐，再同时计算局部 RGB SSIM 和 PSNR。综合分为 `0.8 × max(0, SSIM) + 0.2 × clamp(PSNR / 50, 0, 1)`；PSNR 以 dB 计，不能直接与 SSIM 相加。完美匹配报告上限 100 dB，避免 JSON 中出现 Infinity。80/20 是经过五个正面/背面/盒子回归样本验证的启发式，不代表适用于所有图库。保存两个原始分数和评分版本以便审查。
- 旧条目的已确认图片与候选排序继续复用，不为更换评分算法而全量重跑 CV；旧 `similarity` 没有评分版本时代表 SSIM。候选排序不是语义识别，接近的候选仍需人工看图；没有候选时保持待处理状态，不能写入“已完成的封面回退”。
- `image-reviewed.ts` 记录人工核对的源 URL：102348 应为人物合照而非配件，112019 应为街景而非纯色背景，116622 应为室内背景。固定 URL，不依赖图库序号；后续维护应比对封面与原图。
- 114222 的匹配源是 1000×22691 的长海报，单独的正面官图没有出现在图库中。缓存、响应仍是完整原文件，通过 CSS 显示其中正面区域；`crop` 是原始像素坐标，不生成裁切文件。
- 85291、70818 对应第二张构图，68456 对应第一张；不得退回“取第一张官图”。现有离线夹具覆盖这些反例。

## 存储与运行

```sh
npm run sync:hpoi-images -- --dry-run
npm run sync:hpoi-images
npm run sync:hpoi-images -- --ids=85291,70818,68456,126224
```

默认公开用户 783694，可用 `--user=ID` 修改。CLI 三个有界 worker；生产新增条目单 worker。失败非零退出，完成记录不回滚；后台失败退避一小时。任务中断由后续访问/CLI 发现缺失 ID 后继续。已有记录不自动重跑匹配；更改匹配决策须显式迁移版本，不能覆盖不可变完成凭据。

HF 使用独立前缀 `hpoi-images`。`objects/<sha256>.(jpg|png|webp)` 内容寻址，先上传原文件，再写不可变完成凭据，最后用 ETag CAS 合并 manifest。索引读旧或发布中断时由完成凭据修复，不重复匹配。公开图片接口只接受 hash 与上述扩展名，不能读取任意 HF 对象。

77004 名称没有换行符，先前是全站 `text-wrap: balance` 导致提前折行；卡片保留自然换行与完整标题。128755 采用匹配官图原文件，避免持续依赖源站的封面请求。
