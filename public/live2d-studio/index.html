让画布跟着你的手

⌘ / Ctrl Z · Shift Z
撤销与重做；输入框中保留系统文字撤销。
Delete / Backspace
删除选中文字或人物，包括最后一位人物；可撤销。图层列表需先激活对应行。
⌘ / Ctrl C · V · D
复制、粘贴或直接复制选中对象。人物和文字都可使用，最多三个人物。
[ / ] · Shift + 方向键
将人物后移/前移；按住 Shift 加速移动。
Esc
关闭设置弹窗，或取消对象选择。
点选
点击人物或文字自动切到对应编辑面板，点空白取消选择。
拖拽 / 双指移动
移动当前编辑对象：角色、选中文字或背景。
鼠标滚轮 / 双指捏合
缩放。角色以鼠标所在位置为中心。
双击 / 0
重置当前对象的位置与缩放。
方向键 / ＋ / −
聚焦画布后，精确平移或缩放。
空格
在工作室内暂停或继续动作；输入文字时仍正常输入空格。
◇ · 姿态关键帧
点击参数旁的菱形记录当前值。展开画布下方的动画曲线，拖动菱形调整时间与数值，选择贝塞尔可直接拖动曲线控制柄。双击空白处新增，Delete 删除选中参数的一个关键帧。拖帧会暂停播放，并保留其他手动微调。

动作通过时间轴逐帧采样，播放、拖动和导出保持一致；暂不包含游戏运行时的随机眨眼和完整物理模拟。
创作台通过本站资源接口按需加载模型，已校验的资源最多缓存 128 MB。作品和背景仅保存在当前浏览器；目录不代表每套服装都已逐一人工验收。
